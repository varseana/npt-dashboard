Cursor cuadro :: cyberpunk minimal (B&N)

Recreacion minimalista B&N del reticle/cuadro (el original era un cuadro HUD lleno de texto). Doble tono (borde negro + halo blanco) para verse en light Y dark, hotspot al centro. Pasa el mouse por cada zona. Deci S1 / S2 / S3.

S1 :: marco cuadrado + punto

frame completo
+ centro
Move el mouse aca

S2 :: brackets de esquinas

reticle de
punteria
Move el mouse aca

S3 :: cuadro con esquina recortada

mismo corte que
botones/cards
Move el mouse aca

Al elegir, lo aplico en la app: copio el SVG a public/ y seteo body { cursor: url(...) 16 16, auto }. Solo el cursor por defecto (botones/inputs mantienen pointer/text), salvo que quieras el cuadro en todo.
