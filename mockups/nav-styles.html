Button + dropdown styles

Sharp corners, cero radius, esquina sup-der recortada. Dropdowns sin caja con flecha gruesa a la izquierda. Deci cual (B# / D#).

Buttons :: nav (Dashboard / Team / Access)

Cada fila muestra el estado ACTIVO (seleccionado, solido) y el IDLE (no seleccionado). El corte va solo en la esquina superior derecha.

B1 :: solido sin borde, corte 12
idle = relleno panelAlt (sin borde)
B2 :: outline con borde que sigue el corte, corte 12
idle = borde 1.6px chaflanado
B3 :: corte mas ancho (18), outline
chaflan grande, mas agresivo
B4 :: corte con linea de acento (azul Bauhaus) en la diagonal
solo el activo lleva el acento
B?? :: comparacion de tamano de corte (todos idle outline)
para calibrar cuanto corte te gusta

Dropdowns :: (ej. selector de team / timezone)

Sin borde ni caja de dropdown. Flecha GRUESA a la izquierda para insinuar que despliega. La flecha nativa del navegador va oculta.

D1 :: triangulo relleno grueso a la izquierda
D2 :: chevron doble-trazo grueso a la izquierda
D3 :: chevron grueso + fondo achaflanado SOLO en hover/focus
pasale el mouse por encima
D4 :: triangulo grueso + subrayado (sin caja)

Contexto :: como se veria una barra de nav
